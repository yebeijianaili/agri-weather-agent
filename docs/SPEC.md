# 农田气象时序分析 Agent 规格摘要

## 1. 产品目标

把公开农业气象日值或用户 CSV 转换为可追溯的季节统计、风险提示、自然语言解释和可下载报告，形成“数据进入 - 质量校验 - 分析 - Agent - 导出 - 审计”的完整闭环。

## 2. 角色与场景

- 数据分析人员：导入 CSV、选择地块/年份/季节、运行分析并复核质量；
- 农业管理人员：查看气温、降水、光照、湿度趋势和风险证据；
- 验收人员：通过 API、FastMCP、测试与审计记录复现实验结果。

## 3. 功能契约

| 模块 | 输入 | 输出 | 验收点 |
|---|---|---|---|
| 数据导入 | UTF-8/BOM/GB18030 CSV | 导入批次、行级拒绝原因、SHA-256 | 冲突与异常不污染旧数据 |
| 时序分析 | 地块、年份、季节、日期 | 概览、月度/季节统计、趋势、异常、风险 | 指标由后端统一计算 |
| FastMCP | 工具名与结构化参数 | 工具 trace、结果、耗时、审计号 | 3 个工具可发现、可调用 |
| 本地 Agent | 自然语言问题、analysis_id | 回答、证据 ID、runtime | Ollama 优先，失败时规则回退 |
| 报告导出 | analysis_id 或筛选 | CSV、Markdown、XLSX | 三种格式可下载、可重读、留审计 |

## 4. Excel 交付规格

`GET /api/export/report.xlsx` 返回真正的 OOXML 工作簿：

1. `执行摘要`：任务、时间范围、地块数、记录数、核心指标、分析摘要；
2. `季节统计`：标准字段、自动筛选、冻结表头、季节平均气温柱状图；
3. `风险清单`：风险等级、状态、证据和建议；
4. `方法与口径`：季节、降水、趋势、异常和决策边界。

## 5. 非功能要求

- Windows 双击脚本可启动；
- 页面与依赖全部离线可用；
- API 错误返回结构化 JSON；
- 测试使用隔离数据库和 Mock Transport，不依赖真实网络；
- 正式数据与测试夹具必须清晰区分；
- 温度界面统一显示到小数点后一位；
- 移动端与桌面端均保持可读和可操作。
