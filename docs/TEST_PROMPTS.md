# Agent 与页面验收提示词

以下问题用于现场验收，不是固定回答模板。每次回答应携带真实 `analysis_id`、runtime 和服务端证据。

## 月度与季节

1. 哪个季节降水最多？给出数值并说明是否存在连续少雨风险。
2. 请比较 12 个月，列出最热的三个月并给出证据。
3. 夏季气温与降水有什么特征？不要推断产量。

## 风险与质量

1. 当前有哪些已触发风险？分别引用对应事件证据。
2. 数据质量评分代表什么，不代表什么？
3. 如果湿度存在缺测，哪些结论仍然可用？

## 来源追溯

1. 正式数据来自哪里？列出机构、API 版本、日期范围和记录数。
2. 当前活动数据集是官方数据还是用户上传数据？如何核对哈希？

## 验收判定

- 回答中的指标数字能在返回 `evidence` 中找到；
- 问题是月度排行时，证据覆盖相应月份；
- 风险未触发时不写成已触发；
- 页面展示 `local_model` 或 `rule_fallback` 的真实 runtime；
- 下载的 CSV、Markdown、XLSX 对应同一分析任务。
